## Original v2 photo prompts

Save each image in `assets/originals/rebuild/` (or `assets/source/`) with the exact filename below, then run `pnpm images`. PNG or JPG, at least 1600px on the long side.

Add this line to the end of every prompt:

> High-key editorial photography for a modern Seoul-style dermatology clinic in Manila. Clean white and pale grey surfaces, soft diffused daylight, true-to-life skin with visible texture, subtle mint-green accents. No text, no logos, no watermark.
